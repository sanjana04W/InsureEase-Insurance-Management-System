# Insurance Policy & Claim Management System 🛡️

Sri Lanka's Full-Stack Insurance Management System built with Next.js + MongoDB.

## Features

* Multi-page public insurance website
* Separate admin panel with secure authentication
* Customer management system
* Insurance policy management
* Insurance claim request and approval workflow
* Payment tracking and management
* Dashboard analytics and reporting
* Contact form with MongoDB integration
* JWT-based admin authentication
* Responsive UI with Tailwind CSS
* Complete CRUD operations for all major modules
* Clean and reusable component architecture

## Pages

| Route                                | Description                                                |
| ------------------------------------ | ---------------------------------------------------------- |
| Home (`/`)                           | Landing page with insurance services and policy highlights |
| About (`/about`)                     | Company information and insurance services overview        |
| Policies (`/policies`)               | Available insurance policies listing                       |
| Policy Details (`/policies/[id]`)    | Detailed policy information and coverage details           |
| Claim Request (`/claim-request`)     | Insurance claim submission form                            |
| Claim Status (`/claim-status`)       | Track submitted claim status                               |
| Contact (`/contact`)                 | Customer inquiry and support form                          |
| Admin Login (`/admin/login`)         | Secure admin authentication                                |
| Admin Dashboard (`/admin/dashboard`) | System overview and analytics dashboard                    |

## Getting Started

```bash
# Install dependencies
npm install

# Run both applications
npm run dev
```

| App         | URL                   |
| ----------- | --------------------- |
| Website     | http://localhost:3000 |
| Admin Panel | http://localhost:3001 |
